# 真机验收

## 自动验证

```bash
npm ci
npm run typecheck
npm test
npm run build
```

共九个测试套件。存储测试使用独立的内存 IndexedDB,索引集成测试运行真实导入、落库和召回逻辑,
仅替换 Worker 与 HTTP 边界。它们不能验证浏览器 Worker 加载、CORS、中文 ICU 分词或宿主最终发出的提示词。

本轮修复覆盖:

- 同文重导检查索引是否存在、分词版本及模型,可补向量、恢复本地缺失数据。
- 切换模型后不再用同维度的旧向量;BM25 仍可检索,调试台提示重导。
- 关闭 embedding 后重建,再启用原模型,可以补齐向量。
- 正文、倒排、统计量单事务替换;同步和异步失败均回滚,成功后才刷新缓存。
- 使用宿主提供的本轮聊天查询,排除 swipe 中即将被替换的旧回答。
- 切聊天或停止生成时取消召回;迟到的成功和失败都不能覆盖新轮次。
- 超时和主动取消覆盖响应正文读取,重试等待也可取消。
- 真实召回保存四栏标题与摘要,“看上次真实召回”不再只显示库名和编号;调试台标明手动检索或真实召回来源。

## 真机步骤

复测请在专用测试聊天和测试知识库中操作。样例文件为 `scripts/fixtures/smoke.md`。

| 步骤 | 操作 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| 加载 | 构建后刷新酒馆,点击书本入口 | 面板可打开,控制台无插件初始化错误 | 通过 |
| Worker | 不配置模型接口,导入样例文件 | 完成建库,显示 3 条,BM25-only,Worker 无 404 | 通过 |
| BM25 | 调试台查询“星澜档案馆的蓝铜钥匙由谁保管？” | BM25 / 融合命中档案馆条目,结果含云栖 | 通过 |
| 中文分词 | 查看调试台分词行 | 记录“星澜档案馆”“青梅竹马”“东京都”的实际切分 | 通过 |
| 持久化 | 刷新浏览器后重复查询 | 库与检索结果保留;原文件重导提示无变化 | 通过 |
| 注入 | 在测试聊天中提问并正常生成,查看宿主提示词 | 本轮提示词含知识库参考及正确测试标记 | 通过 |
| Swipe | 重抽一条谈及其他条目的旧回答 | 上次真实召回的查询不包含被替换的旧回答 | 通过 |
| 中止 | 在慢请求期间停止生成或切聊天 | 本轮请求取消,无旧结果写入新聊天 | 通过 |
| 补向量 | 配置 embedding 并测试连接,同文重导 | 重建成功,调试台向量栏有命中 | 通过 |
| 换模型 | 更换 embedding 模型后先检索,再同文重导 | 重导前提示旧模型跳过;重导后恢复向量召回 | 通过 |
| 精排 | 配置 rerank 并测试连接,执行查询 | 精排栏有分数,符合阈值与排序预期 | 通过 |
| 降级 | 在测试端点不可用时查询 | BM25 仍可召回,精排降级使用融合阈值,生成不会因异常中断 | 通过 |
| 清理 | 停用测试库后生成,再删除测试库 | 停用库不参与召回;删除后刷新也不会恢复 | 通过 |

## 后续边界

- 当前字符预算允许首条完整词条超额,表头与分隔符也未计入;长词条需进一步决定是跳过还是采用其他切条策略。
- 关闭总开关后,普通生成会清空注入,但 quiet / impersonate 会跳过召回,需核实是否应立即清空历史注入槽。
- 重导提交已保证三表原子性;检索期间跨多个读取事务遇到并行重导的行为尚需压力验证。
