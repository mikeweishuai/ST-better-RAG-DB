# 星澜档案馆：蓝铜钥匙

星澜档案馆位于雾港城北岸。蓝铜钥匙用于开启地下潮汐卷宗室，由管理员云栖保管，只在日落后借出。借用人必须出示馆内阅览证，并登记预计归还时间。蓝铜钥匙不能打开馆后的花房，也不能用于旅店客房。档案编号：SL-017。记录标记：RAG_ARCHIVE_KEY。

# 星澜档案馆：阅览证

星澜档案馆的阅览证在一层接待台办理，受理时间为每日九点至十七点。申请人须出示雾港临时通行凭证，缴纳十二枚铜币押金。押金在注销阅览证且无欠还资料时退还，阅览证本人使用，不得转借。记录标记：RAG_READER_PASS。

# 星澜档案馆：潮汐卷宗室

潮汐卷宗室位于星澜档案馆地下一层，收藏历年潮位图和港道测绘记录。每日二十点至二十二点接受已登记的阅览者进入，室内禁止明火，只能使用馆方提供的冷光灯。蓝铜钥匙是房门钥匙，持有钥匙不等于免除进入时段和登记要求。记录标记：RAG_TIDE_ROOM。

# 星澜档案馆：温室铜钥匙

星澜档案馆后院花房的钥匙正式名称为温室铜钥匙，由园艺师许苔保管，每日七点至十六点可以办理借用。它的柄端刻有一片叶子。这把钥匙用于花房，不用于地下潮汐卷宗室，也不是蓝铜钥匙。记录标记：RAG_GREENHOUSE_KEY。

# 星澜档案馆：苏澄

苏澄是星澜档案馆的修复师，负责修补受潮的纸质地图，不负责钥匙借用。她每周二、周四下午在二层修复间接受预约，每次最多检查三张地图。修复方案确认前不收取费用。记录标记：RAG_SU_CHENG。

# 星澜旅店：蓝铜客房牌

星澜旅店位于雾港城南街，与北岸的星澜档案馆是两个独立机构。旅店把二楼客房的门牌称作蓝铜客房牌，由前台闻岚管理，住客退房时归还。蓝铜客房牌不能开启档案馆的任何房门，也不适用阅览证制度。记录标记：RAG_INN_TOKEN。

# 苍鹭号：航班与船长

苍鹭号是一艘沿南方海岸航行的帆船，船长名叫陆舟，每周三抵达白沙港。苍鹭号在周三十四点从白沙港东栈桥离港，下一站为赤湾。行李额度为每人一只旅行箱，不载运大型机械。记录标记：RAG_HERON_SHIP。

# 苍鹭号：客票与登船

苍鹭号前往赤湾的普通客票为每人二十六枚铜币，在白沙港东栈桥售票亭购买。登船检查于离港前三十分钟开始，离港前十分钟停止登船。海雾导致停航时，未使用客票可全额退还。记录标记：RAG_HERON_TICKET。

# 苍鹭钟楼

苍鹭钟楼位于雾港城南广场，是一座固定建筑，名称与苍鹭号相近。钟楼每天十八点敲响六次，游客不能进入内部。钟楼没有船长，不售客票，也不经营白沙港至赤湾的航线。记录标记：RAG_HERON_TOWER。

# 陆遥与白沙渡船

陆遥是白沙渡船的船夫，负责白沙港两岸之间的短途摆渡，单次收费三枚铜币，每日六点至十八点运营。陆遥不是苍鹭号船长；苍鹭号也不提供这段短途摆渡。记录标记：RAG_LU_YAO。

# 雾港：步行去北岸

从雾港南广场步行到北岸星澜档案馆，推荐路线依次经过南广场、石桥、北岸长街，正常步行约二十五分钟。雨天石桥湿滑，应放慢脚步。石桥为免费通行的步行桥。记录标记：RAG_ARCHIVE_ROUTE。

# 雾港：夜间渡船

雾港夜间渡船往返南街渡口与北岸渡口，每日十九点三十分至二十三点三十分运营，整点和半点发船。单程航行八分钟，票价五枚铜币。浓雾警报生效时停航。夜间渡船与白沙渡船属于不同线路。记录标记：RAG_NIGHT_FERRY。

# 雾港：浓雾警报

雾港港务处发布浓雾警报时，港口悬挂三角形黄色旗帜，并连续鸣笛三次。警报期间夜间渡船暂停运营，白沙港东栈桥也暂停办理登船；步行石桥仍可通行，但须减速。解除警报后，船务依各自时刻表恢复，不保证立即补发班次。记录标记：RAG_FOG_ALERT。

# 赤砂机车：驱动与检修

赤砂机车以蒸汽驱动，维修站位于西山。更换压力阀前必须先熄火、释放余压并等待冷却；随后由登记技师检查压力表归零。赤砂机车不使用月辉石作为燃料。记录标记：RAG_RED_LOCOMOTIVE。

# 赤砂机车：遗失物

赤砂机车的乘客遗失物由西山维修站的事务员程禾登记，保管期为三十天。领取时须说明遗失日期、车厢位置和物品特征。维修站事务窗口每周一休息，其他日子十点至十六点开放。记录标记：RAG_LOST_PROPERTY。

# 赤砂茶铺

赤砂茶铺位于雾港东街，招牌饮品为烤麦茶，每杯四枚铜币。茶铺每日十一点开门，二十一点关门。它与赤砂机车及西山维修站没有管理关系，不代领乘客遗失物。记录标记：RAG_RED_TEA。

# 月辉石灯

月辉石灯是一种以晶石缓慢发光的照明器具，正常使用时不产生火焰。每次充能后可连续照明六小时，由北岸灯具铺提供充能服务，单次收费七枚铜币。月辉石灯不用于给蒸汽机车提供动力。记录标记：RAG_MOON_LAMP。

# 白沙港：雾铃号

雾铃号是一艘运送谷物的货船，船长为沈砚，每周五到达白沙港。雾铃号不接待普通旅客，不出售前往赤湾的客票。货物交接需持货主签发的提货单，交接地点为西货栈。记录标记：RAG_MIST_CARGO。

# 北岸灯具铺：云岑

云岑是北岸灯具铺的店主，负责冷光灯维修和月辉石灯充能，与星澜档案馆管理员云栖是不同的人。灯具铺每日十点至十八点营业。云岑不办理档案馆钥匙借用，也不签发阅览证。记录标记：RAG_YUN_CEN。

# 雾港：当前档案未收录的事项

现有雾港档案未收录市长生日、林墨私人住址、沉星塔地下室口令和苍鹭号船长的家庭成员。询问这些事项时，只能说明当前资料没有记载；不能从职务、其他人的信息或相似地名推断具体答案。记录标记：RAG_UNKNOWN_FACTS。
